How to read this

  • Functional runs the page's commands in a kind cluster (or a standalone binary) and checks real behavior. A scenario with no type: is functional.
  • Schema checks the page's YAML against its schema without running it: custom resources and Gateway API kinds against their CRDs, core Kubernetes kinds through kubeconform, and standalone config files against agentgateway's schema/config.json, for the release each version tree documents. Helm values and CEL rules are not checked.
  • Hidden checks counts the doc-test assertion blocks in the page's annotation files. A functional test with 0 checks only proves the commands exit cleanly. A dash means the page rebases an upstream page, so its checks live in the upstream product's annotations.
  • Skipped on purpose pages are listed under skip: in tests.yaml (indexes, concept pages, reference). The runner counts them as covered, so its coverage figure is higher than the tested count here.
  • Nightly is the newest completed scheduled or manual run of the content repo's doc-test workflow. Held means the scenario was skipped because its markup needs an update. Not run yet means at least one of the page's scenarios has no result in that run: it was added after the run, or it only exists on a docs-tests branch.
